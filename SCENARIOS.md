### 📁 Структура Page Object классов

```
tests/pages/
├── base_page.py       ← логотип, поиск, корзина в шапке
├── home_page.py       ← главная страница
├── search_page.py     ← результаты поиска
├── catalog_page.py    ← страница категории
├── product_page.py    ← страница товара
├── cart_page.py       ← корзина
└── login_page.py      ← авторизация
```

---

### 💡 Порядок работы

1. Зайди на сайт руками, открой DevTools
2. Для каждой страницы найди нужные селекторы
3. Создай Page Object класс для страницы
4. Напиши тесты используя методы класса
